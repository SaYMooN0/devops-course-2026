# Git в VS Code и терминале

Удобно в VS Code:

1. Сразу видеть изменённые файлы в панели Source Control.
2. Просматривать diff с подсветкой добавленных и удалённых строк.
3. Разрешать merge-конфликты с помощью встроенного редактора.

Удобнее в терминале:

- Просматривать и фильтровать историю командами `git log --oneline --graph --all`.
