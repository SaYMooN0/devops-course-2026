# Сравнение Git и SVN

## Почему ветвление в Git «дешёвое», а в SVN «дорогое»?

В Git ветка представляет собой лёгкий указатель на коммит, поэтому создаётся почти мгновенно и не копирует файлы. В SVN ветвление традиционно реализуется копированием каталогов внутри централизованного репозитория, а дальнейшая работа сильнее зависит от сервера и операций слияния.

## Можно ли сделать коммит в SVN без интернета?

Обычный коммит в SVN без соединения с центральным сервером сделать нельзя. Рабочая копия содержит файлы, но новая ревизия создаётся именно в центральном репозитории. В Git коммиты создаются локально и могут быть отправлены на сервер позже.

## Когда SVN может быть предпочтительнее Git?

SVN может быть удобен в legacy-проектах с уже существующей инфраструктурой, при централизованной модели контроля доступа к отдельным каталогам, а также для больших наборов бинарных файлов, когда полная локальная история каждому участнику не нужна.
